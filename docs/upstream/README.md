# Upstream Archives

This directory preserves documents from the upstream project that AnySys was based on:

- [CONTRIBUTING.md](./CONTRIBUTING.md)
- [release-notes.md](./release-notes.md)

They are kept for historical reference only. They do not describe AnySys processes or releases, and they are intentionally excluded from the main documentation.

The upstream release automation in `.github/workflows/` is not part of the AnySys workflow and was left unchanged in this round.
