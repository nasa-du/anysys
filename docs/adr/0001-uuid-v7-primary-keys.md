# UUID v7 for primary keys

All `User` and `Item` primary keys are generated by the application with UUID v7 (`uuid.uuid7()` from the Python 3.14 standard library), and foreign keys such as `Item.owner_id` carry the same values. We chose v7 over v4 because its time-ordered prefix gives better B-tree index locality on inserts while retaining 74 bits of randomness, which will matter as attendance, scheduling, and payroll tables grow. IDs are still generated in Python rather than by a database default, so the API layer and tests see them immediately and no migration is needed; the existing v4 rows, if any, remain valid. The trade-off is that a v7 ID reveals its approximate creation time, which is acceptable for internal entities and avoids introducing a separate public identifier.
